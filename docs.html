Supply framework

Where the 100T and 50T explanation lives.

This section should answer the question directly instead of leaving people to guess. The cleanest way to present it is as a two-part supply framework: a 100 trillion core operating supply and a 50 trillion expansion and growth allocation.

See growth uses
100T Core
Core operating supply

This is the base TSX supply used as the primary operating structure referenced across the public-facing pages. It is the core supply framework people should associate with the live token system.

50T Growth
Expansion and growth allocation

This allocation is intended for broader ecosystem expansion and future growth needs. It should be explained as a strategic reserve bucket so visitors understand it is separate from the 100T core operating figure rather than a random contradiction.

How to phrase it clearly
100T Core + 50T Growth Framework
The docs page is the right place to state that the project’s broader supply architecture includes a 100 trillion core operating base and a 50 trillion expansion/growth allocation, so the full framework reads clearly instead of sounding inconsistent.
Why this matters: it reconciles the simpler public 100T language with the broader growth planning already being discussed.
Why Docs is the right place: Tokenomics can stay shorter, while Docs carries the more complete explanation.
Why wording matters: visitors need to understand whether they are reading a core operating figure or a broader growth framework.
